# P-09: Per-module utility copy

## Example

```python
# module_a.py
_PROJECT_ROOT = Path(os.environ.get("PROJECT_ROOT", Path(__file__).parent.parent.parent.parent))

# module_b.py — identical
_PROJECT_ROOT = Path(os.environ.get("PROJECT_ROOT", Path(__file__).parent.parent.parent.parent))

# module_c.py — identical
_PROJECT_ROOT = Path(os.environ.get("PROJECT_ROOT", Path(__file__).parent.parent.parent.parent))

# module_d.py — identical
_PROJECT_ROOT = Path(os.environ.get("PROJECT_ROOT", Path(__file__).parent.parent.parent.parent))
```

```python
# module_a.py — with docstring
def _resolve_path(stored_path: str) -> Path:
    """Resolve a DB-stored path to a real filesystem path."""
    ...

# module_b.py — no docstring, verbatim copy
def _resolve_path(stored_path: str) -> Path:
    ...

# module_c.py, module_d.py — same, no docstring
```

## Why it happens

The agent generates in context. When writing a new module, it does not
search for existing utilities — it solves the local problem directly.
Short expressions and small helpers are reproduced by pattern-matching
without registering as duplication.

Creating a shared `config.py` or `utils.py` requires knowing the project's
import structure well enough to add a cross-module dependency — more
coordination than just writing the line again.

The presence of a docstring in the first copy but not in later copies
confirms the function was generated fresh each time, not reused.

## Why it's a problem

- Logic fixes must be applied in N places. A brittle path expression
  (e.g. multiple `.parent` traversals) would silently return the wrong
  value if any file were moved — and it exists in every copy.
- Copies diverge over time: one gets a docstring, a bug fix, or an
  added edge case; the others don't.
- The duplication is invisible until something breaks inconsistently
  across modules.

## Measure

```
Before writing any helper function or module-level constant, search
the codebase for equivalent implementations (search for the function
name, the expression pattern, or the constant value). If found in 2
or more places, extract to a shared module (utils.py, config.py,
paths.py) before adding a new use. Never copy a function between
modules — if it's needed in two places, it belongs in a third.
```
