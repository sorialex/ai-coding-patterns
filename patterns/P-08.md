# P-08: Call-site import bootstrap

## Example

```python
# api/module_a.py — inside a route handler
def process_item(payload: ProcessRequest):
    module_dir = _PROJECT_ROOT / "my_module"
    if str(module_dir) not in sys.path:
        sys.path.insert(0, str(module_dir))
    from processor import process  # deferred, inside function body
    ...
```

```python
# pipeline.py — using importlib to avoid a naming collision
spec = importlib.util.spec_from_file_location(
    "my_module.renderer",
    _PROJECT_ROOT / "my_module" / "renderer.py"
)
renderer = importlib.util.module_from_spec(spec)
spec.loader.exec_module(renderer)
```

`sys.path.insert` guarded by `if dir not in sys.path` appears across
multiple modules. Imports are deferred to function bodies rather than
declared at module level.

## Why it happens

Making a directory properly importable requires coordinated changes across
multiple files: `pyproject.toml` or `setup.py`, `__init__.py`, and import
paths throughout the project. The agent prefers a local one-line fix that
solves the immediate problem without touching anything else.

The defensive guard (`if dir not in sys.path`) shows awareness that this
is a workaround — the agent knows it's not the right solution but applies
it anyway. When a naming collision makes even `sys.path.insert` insufficient,
the agent escalates to `importlib.util` rather than restructuring.

## Why it's a problem

- Import behavior becomes order-dependent and context-sensitive.
- Deferred imports inside function bodies hide module dependencies.
- The fix accumulates: each new module that needs the same package adds
  another `sys.path.insert`, spreading the workaround further.
- Masks a structural problem that compounds with every new module added.

## Measure

```
Never use sys.path.insert or sys.path.append in application code.
If a module is not importable, fix the package structure:
add an __init__.py, update pyproject.toml, or set PYTHONPATH in
docker-compose.yml. All imports must be declared at module level,
not deferred inside function bodies. If a naming collision exists,
rename the module — do not use importlib.util as a workaround.
```
