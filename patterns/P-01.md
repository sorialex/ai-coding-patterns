# UI-01: Buttons without implemented handler

## Example

```jsx
// Stub handler — visually complete, functionally broken
<button onClick={() => {}}>Confirm</button>

// Or handler referenced but never defined
<button onClick={handleSubmit}>Submit</button>
// handleSubmit does not exist
```

## Why it happens

The AI prioritizes completing the visual structure of a component
before its logic. It generates the shape of the interface — layout,
labels, interactive elements — and leaves handlers as stubs,
especially when multiple components are being created in the same
context window.

## Why it's a problem

The component appears finished but silently does nothing on
interaction. This is rarely caught in visual review and only surfaces
during manual testing of each specific action.

## Measure

```
Before considering a UI component complete, verify that every
interactive element (buttons, links, form inputs) has its handler
fully implemented and connected. Do not use () => {} or console.log
as placeholders. A component with stub handlers is not done.
```
